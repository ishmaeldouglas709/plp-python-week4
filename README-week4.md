# PLP Python Week 4

## Overview
This project contains introductory Python exercises focused on defining functions, returning values, using parameters, and working with lists and loops.

## Files

- **`toolbox.py`** — Defines and demonstrates three reusable functions:
  - `double(number)`: returns a number multiplied by 2.
  - `is_pass(score)`: returns `True` when the score is 50 or higher.
  - `greet(name, greeting="Hello")`: builds a greeting using a name and an optional greeting.
- **`welcome.py`** — Defines a `welcome(name)` function and uses a `for` loop to print welcome messages for a list of names.

## Requirements
- Python 3.8 or later
- No third-party packages are required.

## How to Run
Open a terminal in the project directory and run:

```bash
python toolbox.py
python welcome.py
```

## Expected Behavior
- `toolbox.py` prints sample results for the three functions.
- `welcome.py` prints a PLP welcome message for Amina, Brian, and Fatuma.

## Learning Objectives
- Define and call functions.
- Use function parameters and default arguments.
- Return values from functions.
- Use Boolean comparisons.
- Iterate through a list with a `for` loop.
